# 20_Areas

Ongoing responsibilities with a standard to maintain and no end date. One
folder per area. Each holds its own `README.md` (the standard you are
holding yourself to), notes, and links to the projects that currently serve
it.

| Area | Standard |
|---|---|
| Health | Appointments kept, prescriptions managed, questions ready for every clinician, plan followed as given by doctors |
| Hydralada-Marketing | Brief before every asset, five versions per video, published log current, voice guide followed |
| Toop-Street-Property | Safe, maintained, improvements planned and costed before spending |
| Morley-Studio | A working studio and gym: tidy, equipped, inspiring |
| Finance-and-Subscriptions | Every subscription known, justified and reviewed monthly |
| Spirituality | Daily prayer, reading, impressions captured, short accounts kept |
| Relationships-and-Associations | People list current, replies within 48 hours, waiting-for chased weekly |
| IT-Devices-and-Storage | One PARA tree on the NAS, verified backups, devices named and documented |
| Vision-Mission-Values | A living statement, revisited quarterly |
| Journal | A daily entry, weekly reflection, monthly patterns |
| Habits | Each habit designed, tracked, reviewed every two weeks |
