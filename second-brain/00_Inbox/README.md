# 00_Inbox

The single capture point. Anything new lands here first: notes from the
Capture Agent, dictation in `_dictation/`, screenshots in `_screenshots/`,
downloads to sort in `_downloads-to-sort/`.

Rules: nothing stays here longer than one weekly review. The Organise Agent
empties it on Sundays using the PARA Router. `_proposed-tasks.md` holds
tasks in Todoist quick-add format for you to paste in.
