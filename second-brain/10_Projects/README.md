# 10_Projects

Short-term efforts with a goal and an end date. One folder per project named
`YYYY-MM_short-name`, each with a README stating the outcome and target
date, a `packets/` folder for reusable outputs, and a `brief.md` where the
Marketing Brief prompt applies.

Keep this list to 10 to 15 active projects. Pause with a `paused-` prefix,
close by moving to `40_Archives/YYYY_<name>/` with a `CLOSED.md`.
