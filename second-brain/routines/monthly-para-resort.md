# Monthly PARA Re-sort (1st of the month)

Run by the Organise Agent and the To-do Triage Agent together.

1. Re-read every folder under `10_Projects`. For each: still active, with a
   next action this month? If not, prefix `paused-` or propose archive.
2. Promote any `30_Resources` topic that has become a commitment into a
   project folder with a README (outcome, target date).
3. Re-run the To-do Triage generator; review dedupe and stale reports; write
   `_proposed-moves.md`.
4. Pattern pass (Distil Agent) over the month's notes; read the "One Thing".
5. Update `00_Brief/02_master-life-prompt.md` project table.
6. Write `30_Resources/Reviews/YYYY-MM_monthly.md` with: projects closed,
   projects started, top five patterns, subscriptions cancelled, one
   decision for next month.
