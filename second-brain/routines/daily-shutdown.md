# Daily Shutdown (weekdays, 5 minutes)

1. Dictate: wins, anything to put right with someone, loose ends, one thing
   learned, gratitude, tomorrow's One Thing. Save as
   `00_Inbox/_dictation/YYYY-MM-DD_pm.txt`.
2. The Journal Agent appends the Evening Shutdown section to today's journal
   file and writes open loops to `00_Inbox/_proposed-tasks.md`.
3. You: paste the TODOIST block into Todoist (quick add accepts the format),
   close the laptop.

Rule: the day is not over until the shutdown is written. Keep it under 200
words. Forte's "decide, don't do" applies: no working on loose ends now.
