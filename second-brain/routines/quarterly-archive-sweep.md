# Quarterly Archive Sweep (1 Jan, 1 Apr, 1 Jul, 1 Oct)

1. List every folder under `10_Projects` and `20_Areas` with no file changed
   in 90 days.
2. For projects: move to `40_Archives/YYYY_<name>/` with a one-paragraph
   `CLOSED.md` saying what happened and where reusable packets are.
3. For areas: never archive an area; instead note it as "quiet" in the
   quarterly report.
4. Mirror the same moves in Dropbox and the NAS by hand (the agent writes
   the list; you move). Keep names identical.
5. Refresh `30_Resources/twelve-favourite-problems.md`.
6. Write `30_Resources/Reviews/YYYY-Qn_quarterly.md`.
