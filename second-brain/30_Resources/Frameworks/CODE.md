# CODE: Capture, Organise, Distil, Express

Source: Tiago Forte, *Building a Second Brain* (2022) and
https://fortelabs.com/blog/basboverview/. Paraphrased.

CODE is the workflow. PARA is where the output of the workflow lives. Each
stage below has a matching agent in `agents/` and a prompt set in
`30_Resources/Prompts/`.

## C: Capture ("keep what resonates")

- Capture only what surprises you, moves you, or is directly useful. Forte's
  test: does it resonate? Not "might this be useful one day".
- Twelve favourite problems. Keep a list of the dozen open questions you are
  always trying to answer. Capture anything that touches one of them.
- Capture into one inbox, from every device, in seconds. The friction of
  capture must be near zero; the thinking happens later.
- For Brad: Todoist Inbox, Remarkable, voice notes, Pinterest saves, browser
  bookmarks, screenshots, WhatsApp forwards. All flow to `00_Inbox` via the
  Capture agent.

## O: Organise ("save for actionability")

- File by the project or area the item will help with, not by topic. That is
  what PARA is for.
- Do it in batches during the weekly review, not at capture time.
- When unsure, put it in the project you are working on right now. It can be
  moved later.

## D: Distil ("find the essence")

- Progressive Summarisation: layer 1 the captured note, layer 2 bold the key
  passages, layer 3 highlight the best of the bold, layer 4 write a short
  executive summary in your own words, layer 5 (rare) remix into something
  new. See `Progressive-Summarisation.md`.
- Distil opportunistically, each time you touch a note for a real reason, not
  as a chore.
- Design notes for your impatient future self. Discoverable first, complete
  second.

## E: Express ("show your work")

- The only point of the system is output: a brief, a video, a post, a plan,
  a decision, a conversation.
- Work with Intermediate Packets: small reusable pieces (an outline, a set of
  quotes, a shot list, a template) that can be assembled into bigger work.
- Ship smaller things sooner. Get feedback. Re-capture what you learn.
- For Brad: Substack posts, Hydralada campaigns, Mission and Vision posters,
  NEXUS app copy, testimonial videos, quote cards (see `/cards` in this repo).

## The loop in one line

Capture to `00_Inbox` daily, organise to PARA weekly, distil whenever you
revisit, express at least one Intermediate Packet a week.
